# Vexel MedSIMS Android

Native Kotlin/Jetpack Compose client foundation for Vexel MedSIMS. See `../docs/ANDROID_DEVELOPMENT_AGENT_CONTEXT.md` for authoritative environment and deployment rules.

Run `./gradlew :app:assembleDebug` from this directory. The production API root is `https://sims.vexel.pk/` and Retrofit endpoints include the `api/` prefix exactly once.
