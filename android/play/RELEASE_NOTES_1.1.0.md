# MedSIMS 1.1.0 — Faculty delivery candidate

Faculty users can now view role-specific dashboard statistics, browse their paginated session list,
load and search a live roster, mark individual or all students present/absent, review confirmation
counts, and submit attendance directly to the production API. Failed writes are never queued.

This release retains the completed Student services, including compliance document submission,
authenticated learning/submission downloads, fee-statement PDFs, and secure system-viewer handoff.
