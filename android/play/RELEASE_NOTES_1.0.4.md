# MedSIMS 1.0.4 — Student internal-testing candidate

Student services now includes paginated notifications, unread and read-all actions,
text or document compliance submissions, rejected/locked requirement states, authenticated
learning and prior-submission downloads, fee-statement PDF download, and secure system-viewer
handoff. Profile and password forms provide client-side and server field validation feedback.

Downloaded files are streamed into temporary app cache and removed at logout. External links
never receive the MedSIMS bearer token. Faculty dashboard and live-attendance work is present in
the development build but remains disabled in this Student-only release pending v1.1.0.

This candidate is not uploaded to Google Play. It is online-first: student mutations are
never queued or replayed when offline.
